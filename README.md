# Hands-On Data Analysis

A practical Data Analytics project featuring hands-on assignments and implementations using **Microsoft Excel, Power BI, and MySQL**. This repository contains practical exercises covering data manipulation, analysis, visualization, reporting, database management, and automation.

## Project Overview

This project focuses on applying core Data Analytics concepts through practical assignments using different datasets. Each module covers a range of concepts and techniques to perform data analysis, generate reports, build interactive dashboards, and work with relational databases.

The project is organized into three modules:

- **Excel Assignments**
- **Power BI Assignments**
- **SQL Assignments**

## Tools & Technologies

| Tool | Purpose |
|---|---|
| Microsoft Excel 2016 | Data Analysis, Functions, Reporting & Automation |

| MySQL Workbench | Database Management & SQL Query Execution |

## Modules & Concepts Covered

### 1. Excel Assignments

**Tool:** Microsoft Excel 2016

Practical implementation of Excel functions, data manipulation, visualization, dashboard development, and automation.

**Concepts Covered:**

- **Arithmetical Functions:** SUM, AVERAGE, MIN, MAX, COUNT and related calculations.
- **Logical Functions:** IF, AND, OR and conditional calculations.
- **Lookup & Reference Functions:** VLOOKUP, INDEX, MATCH and combined lookup techniques.
- **Date & Time Functions:** TODAY, NOW, DAY, MONTH, YEAR, DATEDIF and date calculations.
- **Data Sorting & Filtering:** Custom sorting, multiple criteria sorting, text-based filtering and date filtering.
- **Data Visualization:** Line Charts, Combo Charts and chart formatting.
- **Power Query:** Data import, cleaning, transformation and loading into the Data Model.
- **Power Pivot:** Relationships between multiple worksheets and Data Model management.
- **Dashboard Development:** Interactive reports, Slicers, Timeline and dashboard formatting.
- **Macro & VBA Automation:**
  - Automated sales amount calculation using Quantity × Unit Price.
  - Macro button creation and assignment.
  - New Joinee Form for capturing Name, Age and Gender.
  - Submit button automation and saving employee details into an Excel worksheet.

**Dashboard Implementation:**

Developed a Sales Analysis Dashboard using the Sales Dataset, covering:

- Most Used Shipment Mode
- Top 5 Profitable States
- Top 3 Least Profitable Product Sub-Categories
- Top 10 Most Profitable Cities
- Additional business insights from the dataset.

### 2. Power BI Assignments

**Tool:** Power BI Desktop

Practical implementation of data modeling, DAX calculations, data visualization, interactive reporting, and dashboard development.

**Concepts Covered:**

- **Power BI Fundamentals:** Power BI introduction and its different platforms.
- **DAX (Data Analysis Expressions):**
  - Current Year vs Previous Year Sales Analysis.
  - Year-over-Year (YoY) Sales Growth Percentage.
  - DAX-based calculations and measures.
- **Power Query & Data Transformation:**
  - Importing data from external web sources.
  - Appending historical yearly datasets.
  - Creating a consolidated Master Table.
- **Data Modeling:** Data preparation and model management.
- **Data Visualization:**
  - Line and Clustered Column Charts.
  - Waterfall Charts.
  - Donut Charts.
  - Clustered Column Charts.
  - Table Visuals and Cards.
- **Hierarchies:** Creating Location Hierarchy using Country, State, Region, City and Postal Code.
- **Bookmarks:** Interactive Year-wise, Quarter-wise and Month-wise analysis.
- **Drill Through:** Region-wise Profit Analysis with detailed West Region reporting.
- **Conditional Formatting:**
  - Background color formatting.
  - Icon-based formatting.
  - Data bars.
  - Font color formatting.
- **Dashboard Development:**
  - Finance Dashboard.
  - Navigation buttons.
  - KPI Cards.
  - Charts and interactive visuals.
  - Website hyperlinks.
  - Slicers and dashboard formatting.

**Datasets Used:**

- Sample Superstore Dataset
- Finance Dataset
- Worldwide Box Office Data (Box Office Mojo)

### 3. SQL Assignments

**Tool:** MySQL Workbench

Practical implementation of SQL queries, database design, data retrieval, aggregation, relationships, and advanced SQL operations using the Classic Models database and custom tables.

**Concepts Covered:**

- **SQL Fundamentals:** SELECT, WHERE, DISTINCT, AND, LIKE, ORDER BY.
- **Conditional Logic:** CASE Statements and Customer Segmentation.
- **Aggregate Functions:** SUM(), COUNT(), AVG(), GROUP BY and HAVING.
- **Date & Time Functions:** Month extraction and payment analysis.
- **Database Design & Constraints:** PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, CHECK, DEFAULT and AUTO_INCREMENT.
- **SQL Joins:** Table Joins and Self Joins.
- **DDL Commands:** CREATE, ALTER and RENAME.
- **Views:** Creating views for product category-wise sales analysis.
- **Stored Procedures:** Procedures with input parameters for year-wise and country-wise payment analysis.
- **Window Functions:** RANK(), DENSE_RANK(), LEAD() and LAG().
- **Subqueries:** Nested queries and aggregate-based analysis.
- **Error Handling:** Stored procedure error handling and exception handling.
- **Triggers:** BEFORE INSERT triggers for data validation and transformation.

**Database Used:**

- Classic Models Database
- Custom databases and tables created as part of SQL assignments.
